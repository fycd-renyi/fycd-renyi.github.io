# 六十甲子籤互動頁

這是一個可以直接放到 GitHub Pages 的純靜態網站，不需要伺服器或資料庫。

## 使用方式

1. 在你的 `fycd-renyi.github.io` repository 建立 `fortune` 資料夾。
2. 把這個資料夾內的以下檔案上傳到 `fortune/`：
   - `index.html`
   - `style.css`
   - `app.js`
   - `logic.js`
   - `fortunes.js`
3. GitHub Pages 更新後即可開啟：
   `https://fycd-renyi.github.io/fortune/`

## 現在的互動流程

- 首頁不要求輸入問題，也沒有類別選單。
- 使用者只需要在心中默想所求之事。
- 點「誠心求籤」後，木質籤筒與筒內籤枝會一起晃動，其中一支籤會升起。
- 抽到籤後進入擲筊確認。
- 每一次擲筊都由使用者自己點按鈕觸發。
- 必須連續三個聖筊才顯示正式結果；途中若出現非聖筊，本支籤不成立並重新求籤。
- 結果頁顯示：籤號、干支、吉凶、原始籤文、完整籤意、解說參考，以及事業、財運、感情、健康、出行、訴訟／爭議、家庭參考。
- 支援繁體中文 / English 切換。

## 籤文與解讀

原始籤文依通行的六十甲子籤版本整理；英文意譯、完整籤意與分類參考為方便理解所編寫，應視為文化與自我反思參考。
